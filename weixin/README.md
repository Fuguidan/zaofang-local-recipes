# 灶房微信小程序

这是“灶房”本地优先菜谱应用的微信小程序版本。菜谱、设置、推荐历史、诊断日志和图片都保存在当前微信设备的小程序本地空间，不使用业务服务器，也不要求登录。

## 已实现功能

- 菜谱新增、查看、修改、取消和二次确认删除；同名菜谱保存前提示。
- 图片上传、HEIC 本机转换尝试、裁剪、缩放、拖动和旋转；编辑结果作为统一封面。
- AI 仅文字生成、图片加文字识别、思考开关、文本/图片能力测试和 Token 分类统计。
- 按人数、餐次、口味、荤素和标签进行本地推荐，默认菜品数为人数加一。
- 本地营养计算，支持热量、蛋白质、碳水、脂肪、膳食纤维和钠；内置 7,342 条食物标准数据及中英文搜索。
- 列表/缩略图两种首页布局，每页 10 条。
- 流式 ZIP 导入导出、冲突处理、失败回滚和脱敏诊断日志。

## 在微信开发者工具中运行

1. 安装并打开微信开发者工具。
2. 选择“导入项目”，项目目录选择本 `weixin` 文件夹。
3. AppID 使用 `project.config.json` 中的项目 AppID，或替换成自己的小程序 AppID。
4. 点击“编译”。首页、推荐、数据、设置四个入口位于底部导航。

本地自动化检查：

```bash
cd weixin
npm test
npm run check
```

测试不需要安装第三方依赖。

## AI 配置

在“设置”中打开“允许使用 AI 生成”，填写 HTTPS 接口、模型和 API Key。API Key 只保存在微信本机缓存，不写入源码、业务 ZIP 或诊断日志。

真机请求还必须在微信公众平台完成配置：

1. 登录微信公众平台。
2. 进入“开发管理 → 开发设置 → 服务器域名”。
3. 在 `request 合法域名` 中加入模型接口域名，例如阿里云百炼兼容接口使用 `https://dashscope.aliyuncs.com`。
4. 接口必须使用有效 HTTPS 证书，不允许只填写 IP、localhost 或带路径的域名项。

开发者工具中的“不校验合法域名”只对本机调试有效，真机体验版仍以公众平台配置为准。文本连接成功也不代表模型具备视觉能力，可分别使用“测试文本连接”和“测试图片能力”。

## 生成体验版

1. 在开发者工具右上角点击“上传”，填写版本号和说明。
2. 在微信公众平台“管理 → 版本管理”中找到开发版本。
3. 设为体验版，并在“成员管理”中添加体验成员。
4. 将体验二维码分享给已添加的体验成员。

无需正式上架即可给少量成员试用。每台手机的数据彼此独立；更换设备或清除微信数据前请先导出 ZIP。

## 导入导出说明

导出先在小程序沙箱中流式生成标准 ZIP，再由用户主动分享到聊天或保存。图片按 256 KB 分块读取和写入，不会因一次性把 20 MB 以上图片装入内存而闪退。微信不允许小程序任意写入手机文件夹，所以不能像 Android 原生选择任意路径；分享或微信文件面板是小程序允许的交付方式。

业务备份包含菜谱、图片、非敏感设置和推荐历史，不包含 API Key、诊断日志或错误堆栈。

## 本地数据边界

- `wx.setStorageSync`：菜谱元数据、设置、推荐历史、有限容量日志。
- `wx.env.USER_DATA_PATH/recipe-images`：菜谱图片。
- `wx.env.USER_DATA_PATH/backups`：用户生成的 ZIP。
- 不使用云开发、远程数据库、自动遥测或自动日志上传。

卸载小程序、清理微信存储或系统回收空间都可能删除本地数据，重要数据请定期导出。
