# 灶房

一个数据留在本机的中文菜谱 PWA。支持菜谱增删改查、按人数和餐次进行本地规则推荐、完整 ZIP 备份、离线安装、脱敏诊断日志，以及可关闭的远程图片解析。

## 隐私边界

- 菜谱、图片、标签、推荐历史、模型配置和诊断日志保存在浏览器 IndexedDB。
- 不使用账号、云数据库、云同步或自动遥测。
- 远程图片解析默认关闭。启用后只发送当前图片、补充文字和固定解析提示。
- API Key、诊断日志和错误堆栈不进入业务 ZIP 备份。
- 浏览器本地保存的 API Key 不具备操作系统密钥链级别的保护。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

构建与测试：

```bash
npm run typecheck
npm run test
npm run build
```

## 使用流程

1. 在“我的菜谱”中添加、编辑或删除菜谱；无 API Key 时图片和原始文字仍可直接保存。
2. 在“今日推荐”输入人数、餐次、口味和标签。默认推荐菜品数为人数加一。
3. 在“数据管家”导出完整 ZIP；换设备后选择同一 ZIP 即可恢复。
4. 在“设置与诊断”主动开启调试模式、下载脱敏日志或配置支持图片输入的兼容模型接口。

详细开发进展见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)。
