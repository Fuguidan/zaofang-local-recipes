# 灶房开发记录

本文件与每次功能提交同步更新。日志、API Key、用户菜谱、临时图片和 ZIP 备份不进入 Git。

## 提交记录

- `chore(project): 初始化PWA与开发规范`：完成项目、Git、依赖、构建和文档基础。
- `feat(app): 完成本地菜谱核心功能`：实现本地存储、菜谱管理、推荐、备份、离线、诊断和图片 AI 配置。
- `test(app): 完成核心功能综合验收`：覆盖推荐、ZIP、隐私、渲染和浏览器端菜谱生命周期。
- `chore(hosting): 绑定生产站点`：保存托管项目标识，数据绑定保持为空。

## 2026-07-27 · 阶段一：项目、Git 与诊断基础

- 目标：建立 PWA 骨架、基础视觉、统一日志和异常处理。
- 修改：完成四个主功能入口、响应式布局、错误边界、错误编号、脱敏日志、循环容量、筛选、下载与清空。
- 决策：生产环境默认只记录警告和错误；调试模式由用户主动开启；诊断日志不自动上传。
- 测试：类型检查、生产构建、服务端渲染、浏览器加载和日志脱敏均通过。
- 已知问题：暂无。
- 下一步：完成本地数据和菜谱管理。

## 2026-07-27 · 阶段二：本地数据层

- 目标：业务数据只保存在当前设备。
- 修改：使用 IndexedDB 建立菜谱、设置、推荐历史和日志存储；实现事务、数据库升级和日志上限。
- 决策：图片 Blob 与菜谱记录存放在同一事务对象中，删除菜谱时同步删除图片。
- 测试：增加数据持久化路径的类型和构建验证；浏览器端事务由菜谱及导入流程覆盖。
- 已知问题：浏览器隐私模式可能限制可用存储空间，界面会转换为本地存储错误。
- 下一步：完成菜谱管理。

## 2026-07-27 · 阶段三：菜谱完整管理

- 目标：完成添加、查看、修改、取消和删除流程。
- 修改：支持图片、原始说明、食材、步骤、餐次、口味、标签、分类、耗时和难度；不完整内容可保存为待完善菜谱。
- 决策：未填写菜名但有图片或说明时保存为“待完善菜谱”；空食材和空步骤不写入。
- 测试：已在浏览器完成新增、刷新持久化、修改、取消与二次确认删除的完整交互验证。
- 已知问题：暂无。
- 下一步：实现本地推荐。

## 2026-07-27 · 阶段四：本地规则推荐

- 目标：根据人数、餐次、口味和标签推荐菜品组合。
- 修改：默认人数加一道菜；支持近期去重、固定菜品、换一道和整组重选。
- 决策：食材用量不随人数换算；餐次不匹配的菜谱直接排除。
- 测试：覆盖 1/2/4 人对应 2/3/5 道、餐次筛选、菜谱不足、固定和去重。
- 已知问题：首版使用确定性评分，不计算营养素。
- 下一步：实现 ZIP 数据管理。

## 2026-07-27 · 阶段五：ZIP 导入导出

- 目标：实现完整备份、验证预览和安全恢复。
- 修改：ZIP 包含版本化清单、JSON、图片和推荐历史；导入前校验结构和图片；相同 ID 默认使用备份版本。
- 决策：API Key 和诊断日志永不进入业务备份；写入通过 IndexedDB 事务完成。
- 测试：覆盖中文菜谱、图片往返、API Key 排除和损坏 ZIP。
- 已知问题：首版冲突策略在预览中明确提示，默认由备份版本覆盖同 ID。
- 下一步：完善离线能力。

## 2026-07-27 · 阶段六：PWA 与离线能力

- 目标：支持安装和离线访问核心本地功能。
- 修改：增加应用清单、Service Worker、应用外壳缓存和缓存更新清理。
- 决策：同源 GET 使用网络优先、缓存回退；远程 API 不进入 Service Worker 缓存。
- 测试：生产构建和服务端渲染通过，浏览器端成功注册 Service Worker。
- 已知问题：首次访问仍需联网加载应用资源。
- 下一步：最后接入图片 AI。

## 2026-07-27 · 阶段七：图片 AI 与模型配置

- 目标：在本地能力稳定后增加可关闭的远程图片解析。
- 修改：支持兼容接口地址、模型名、API Key、开关和连接测试；解析结果进入可编辑表单。
- 决策：只发送当前图片、补充文字和固定提示；无 Key、失败、取消或异常响应均保留原始内容。
- 测试：通过类型与构建验证请求结构、异常转换和密钥脱敏；实际模型能力由用户配置的服务决定。
- 已知问题：浏览器直连接口需要服务提供方允许 CORS，且模型必须支持图片输入。
- 下一步：综合验收。

## 2026-07-27 · 阶段八：综合验收与发布准备

- 目标：完成隐私、错误恢复、测试和发布检查。
- 修改：完善 README、测试用例、诊断提示、响应式、无障碍状态及品牌分享封面 `public/og.png`。
- 决策：应用部署只提供静态程序资源，不启用 D1、R2、登录或云同步。
- 测试：类型检查通过；6 项领域测试和 1 项服务端渲染测试通过；生产构建通过；浏览器验证菜谱增删改查和 2 人推荐 3 道菜通过。
- 已知问题：浏览器自动化环境未捕获到由临时链接触发的下载事件，ZIP 生成、解析、图片往返、密钥排除和损坏文件拒绝已由领域测试覆盖。
- 下一步：根据真实使用反馈迭代推荐规则与备份冲突交互。
